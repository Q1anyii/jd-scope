# 2026-11-21 · 项目初始化

从「需求分析」直接落到可运行产物的一天。记录当天发现并修掉的缺陷，便于回溯规则。

## 1. 模块导入顺序错误（阻断级）

`app/lexicon.py` 在模块级循环里构造 `TERMS` 时调用了 `normalize()`，而该函数定义在循环之后，
导致 `NameError: name 'normalize' is not defined`，整个服务无法启动。

处置：把 `normalize()` 提到模块顶部，先定义再使用。教训是「模块级循环里不能调用本模块后置定义的函数」。

## 2. 岗位名被截断

JD 里的 `岗位名称：AI 应用开发工程师（Agent 方向）` 只抽出 `应用开发工程师`。
原因：`TITLE_RE` 的字符类里没有空格，「AI 」被切断。

处置：两层修复。
- 字符类补 `\s`；
- 新增 `_meta_value()`，优先按「键：值」形态读元信息行（公司/岗位/地点），正则只在没有元信息时兜底。

## 3. 工作年限漏识别

`2 年以上开发经验` 匹配不到，因为原正则从 `以上` 直接跳到 `经验`，中间不允许出现别的词。

处置：改成 `(\d{1,2})\s*年(?:及)?以上[^\n，。；]{0,8}?经验`，允许中间有短修饰（开发 / 相关 / 项目）。

## 4. 术语嵌套误匹配

`熟悉 MySQL` 同时命中 `MySQL` 和 `SQL`，`Spring Boot` 同时命中 `Spring Boot` 和 `Spring`，
导致同一句话被算两次命中，分数虚高。

处置：`find_terms()` 改为「最长匹配优先 + 区间不重叠」——先收集所有出现区间，按长度降序贪心占位，
被覆盖的短别名丢弃。

## 5. 过泛别名造成误报

`文档` 作为 `文档写作` 的别名，会让「负责文档切分与入库」被判定为具备文档写作能力。

处置：删除裸 `文档`，只保留 `文档写作 / 技术文档 / 需求文档 / 手册 / sop`。
规则：别名词必须能单独成立，不能是高频普通词。

## 6. 报告「判定依据」为空

`analysis.verdict_reason` 计算出来但没落库，导出报告时只读得到 `score_json`，于是该行为空。

处置：`score_json` 增加 `verdict_reason` 字段（创建与重算两处都写），导出时读取；前端详情页也改用该字段。

## 7. 端口冲突导致静默启动失败

打包后的 exe 首次启动无任何反应。排查发现测试端口 8901 已被系统里另一个进程占用，
`ThreadingHTTPServer` 抛 `OSError`，而 `--windowed` 模式没有控制台，异常无人可见，进程直接退出。

处置：
- 新增 `_bind_server()`，指定端口失败时退回 `port=0` 由系统分配；
- 新增 `_say()`，窗口模式下 `sys.stdout is None` 时跳过打印，避免 `print` 抛异常。

## 8. 打包脚本编码问题

`build/build_exe.ps1` 含中文提示，被 Windows PowerShell 5.1 按 ANSI 解码，
`Write-Host ("完成：" + ...)` 的引号被吃掉，整个脚本解析失败。

处置：脚本内提示改为纯 ASCII。中文只保留在 README 与 devlog（UTF-8 文本文件，不参与执行）。

## 9. 重算冲掉缺口进度（自审发现）

`_persist_analysis()` 采用「先删后插」，导致点一次「重算」就把人工标注的缺口状态（补课中 / 已补上）
和已经生成的面试应答口径全部清空。这是使用者一定会踩到的坑。

处置：重算前先读出旧缺口的 `(requirement, status, answer, action)`，插入后按 `requirement` 文本回填。
新增一个接口级集成测试 `test_gap_status_and_answer_survive_recalc` 固定该行为。

同时删掉前端遗留的空函数 `renderBaseOptions()` 及其调用（未实现基底切换，属死代码）。

## 10. 验证方式

- 24 个用例：词表最长匹配、JD 三段切分、硬性条件判定、基底选型、聚合、报告结构，
  以及 HTTP 接口链路（健康检查 / 静态资源 / 缺口进度保留 / 报告导出）
- 接口联调：health / parse / bases / jobs / stats / export 全链路
- 打包后验证：进程存活、窗口标题正确、端口可访问、`/api/bootstrap` 返回 200
- 界面验证：无头浏览器渲染后检查 DOM（5 张统计卡、7 个导航项）与窗口位图截图
